# VidTextSwap demo

Change a phone number, branch name, website or date inside your videos and images.
The new text keeps the original size, colour, outline and boldness.

This Space runs the open-source tool from
[github.com/mohammedsaif/vidtextswap](https://github.com/mohammedsaif/vidtextswap).
The free CPU here suits short clips. For long or private videos, install the tool and
run it on your own computer.
